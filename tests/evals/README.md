## Проверка одной командой без ключа и без API

Из корня распакованного архива, после установки зависимостей:

```powershell
python -m pip install -r tests/evals/requirements.txt
python tests/evals/verify_all.py
```

Команда проверяет набор, запускает 11 тестов, исторический replay с порогами,
проверяет исходные live-доказательства и новый пересчёт, отдельно запускает
референсную диагностику поиска. CI выполняет те же offline-проверки.

## API и сохранность

Новых API-вызовов при исправлении и пересчёте нет. run.py сохраняет режим
free-api и защиту бесплатного маршрута, но текущие live-файлы относятся к прежней
версии. Он не разрешает затереть существующий прогон или продолжить его с другим
хешем набора. Новый эксперимент требует отдельного рабочего каталога/версии,
своего локального ключа и подтверждённого бесплатного режима.
Никаких ключей в архиве/Git нет. ApiMira не использовалась.

Пакет переносится ровно в docs/quality/golden-dataset/, tests/evals/ и
.github/workflows/evals.yml. REPORT.md содержит текущие цифры и ограничения.
Проверка структуры, согласование эталонов и успешный CI не означают принятие
всей лабораторной преподавателем или готовность продукта.
