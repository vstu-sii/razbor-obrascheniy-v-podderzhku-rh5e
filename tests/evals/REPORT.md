# LAB03: baseline на текущем golden dataset

Основной результат — evidence/baseline-report.json, источники —
evidence/baseline-source-manifest.json (также source-manifest.json),
покрытие каждой записи — evidence/baseline-coverage.json.

Это новые реальные ответы Mistral ministral-14b-2512 от 15.10.2026,
а не исторический replay LAB02. Использованы инструкции prompt-v2.md,
текущий согласованный golden dataset v2.1-reviewed и синтетическая KB.

## Полнота покрытия

- cases.jsonl: **43 из 43 записей покрыты**.
- **38 разных входных групп**, 38 реально полученных ответов.
- Пять записей — исторические регрессионные копии одинакового входа и gold.
  Для каждой программно проверено совпадение ticket/history/KB/candidate_proposal
  и expected, после чего указан соответствующий реальный request_id.
- 43 строки baseline-responses.jsonl — покрытие записей, а не 43 независимых вызова.
  Главные метрики считаются по baseline-independent-responses.jsonl: 38 групп.
- Ещё шесть записей live-regressions.jsonl — отдельные связанные регрессии;
  их тождественность базовым входам проверяет validator, но в 43 основного набора
  они не подмешиваются и знаменатель независимых метрик не увеличивают.

Режим 33/38 ниже инженерной цели 90%; это сохранённый дефект, не закрытая цель.

## Воспроизводимая проверка без API

После установки requirements.txt из корня репозитория:

```powershell
python tests/evals/run.py --mode baseline
```

Команда пересчитывает реальные сохранённые результаты, проверяет 43/43,
38 групп, хеши, связь повторов, дополнение тайм-аутов и зафиксированные пороги.
CI выполняет эту команду. Это воспроизведение нового live-эксперимента из
сохранённых ответов, не утверждение о новом API-вызове при каждом запуске CI.
Слепая независимая проверка обобщения и запуск всего приложения не заявлены.
Контекст статей задан фикстурой, поэтому это baseline генерации, не измерение
поиска и развёрнутого AI Engineer сервиса.
