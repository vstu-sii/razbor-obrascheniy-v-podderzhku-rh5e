# Глоссарий

- **Обращение** — текстовое сообщение клиента о вопросе или проблеме.
- **Тикет** — единица учёта обращения и его истории.
- **Первая линия** — команда, принимающая основной поток.
- **AI-первая линия** — этап, на котором AI пытается обработать типовой вопрос.
- **Оператор** — человек, принимающий решение.
- **Triage** — первичный разбор темы, срочности, контекста и маршрута.
- **Категория** — нормализованный тип проблемы.
- **Срочность** — требуемая скорость реакции, а не слово «срочно».
- **Эскалация** — передача обращения оператору или другой линии.
- **База знаний** — утверждённые материалы для ответа.
- **Фрагмент** — найденный раздел статьи.
- **Retrieval** — поиск релевантных фрагментов.
- **Единый поиск** — поиск по БЗ, истории и документации.
- **Summary** — краткая выжимка диалога.
- **Чек-лист** — список известных и недостающих данных/действий.
- **Черновик ответа** — предложение текста для проверки оператором.
- **Контекст эскалации** — summary, данные, источники и причина передачи.
- **Уверенность** — оценка надёжности результата.
- **Prompt injection** — инструкция внутри текста, пытающаяся изменить правила AI.
- **Golden dataset** — набор примеров с эталонной разметкой.
