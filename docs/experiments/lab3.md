# Лабораторная работа 3. Baseline разбора обращений

Дата эксперимента: 15.10.2026. Задача — получить структурированную карточку
для оператора поддержки: тему, срочность, известные факты, недостающие данные,
следующий шаг, источники и черновик ответа. Режимы: `answer`, `clarify`,
`escalate`. Финальное действие подтверждает оператор.

## Реализация

[Baseline](../../ml/models/baseline.py) включает поиск BM25 по утверждённым
статьям нужной версии, извлекающий алгоритм и адаптер chat-completions API.
Адаптер запрашивает карточку через `propose_card`; функция не выполняет
внешних действий. Полученный объект проверяется по JSON Schema и по точному
совпадению источников с переданными фрагментами. Допускаются две попытки
в пределах общего ограничения 55 секунд. При ошибке возвращается
`not_analyzed/escalate` с передачей оператору.

[AI API](../../backend/routers/ai.py) предоставляет `/v1/analyze` и `/health`.
Вход проверяется Pydantic; вызов модели выполняется в рабочем потоке.
[Конфигурация трассировки](../../ml/tracing/README.md) описывает Langfuse SDK
и локальный журнал вызовов.

## Условия модельного эксперимента

Модель: `ministral-14b-2512`, прямой Mistral API. Использован Free-аккаунт,
подтверждённый владельцем. Температура 0, лимит 1600 выходных токенов.
Инструкции: [prompt-v2.md](../../ml/experiments/prompt-v2.md).
Запрошен forced tool call `propose_card`; проверка полной схемы выполняется
после получения ответа.

Набор содержит 43 согласованные синтетические записи: 38 разных входов
и пять тождественных регрессионных копий. В UC-04 модели передано прежнее
предложение карточки. Статьи БЗ для генерации заданы входными фикстурами.
Это измерение генерации при заданном контексте; работа поиска оценена отдельно.

Первый проход дал 34 ответа и четыре тайм-аута. Затем выполнены четыре вызова
для отсутствовавших ответов. Успешные ответы повторно не запрашивались.
Всего сохранено 42 попытки; итоговые показатели ниже рассчитаны по
38 полученным ответам разных входов. Первоначальные тайм-ауты входят в CSV.

Метрики рассчитаны по исходным карточкам до ручного fallback. Время включает
обращение к API; полный путь через UI, общую очередь и БД в этот замер
не входит. Для четырёх первоначальных тайм-аутов usage неизвестен.
Фактическая стоимость в рублях по биллингу не установлена.

Отдельная диагностика BM25 на 28 сценариях, исключая UC-04, дала Recall@3
0,875 на восьми входах с эталонными источниками. На 13 входах без эталонного
источника найдены лексически похожие статьи. Результат относится к поиску;
фикстурный контекст модельного прогона не используется для оценки ретривера.

## Ошибки и значение для продукта

Пять ответов выбрали неверный режим. Например, UC03-10 и EDGE-STALE-01
получили `clarify` вместо ожидаемой передачи специалисту. Ещё два ответа
ошиблись в категории. Проверка схемы и цитат подтверждает структуру и
происхождение фрагментов; содержательную точность текста оценивают отдельно.

Основное направление улучшения — выбор режима и достаточность основания
для ответа. Набор использован при настройке инструкций, поэтому результат
характеризует текущий учебный набор. Показатель 0/28 не подтверждает
продуктовый предел ошибки 2% на новых обращениях.

Модельный эксперимент использует отдельный runner с `prompt-v2.md` и
подготовленным контекстом. HTTP baseline использует собственный BM25 и
инструкцию из `baseline.py`; приведённые показатели относятся к runner.
Проверка dashboard Langfuse в протокол этого прогона не входит.

## Воспроизведение

Из корня репозитория, Python 3.12:

```powershell
python -m pip install -r ml/requirements.txt
python ml/experiments/check_baseline.py
python ml/experiments/retrieval.py
```

Первая команда проверки сопоставляет 43 записи, 38 разных входов,
хеши набора и ответов, исходные тайм-ауты и четыре дополнительных ответа.
Ноутбук: [lab3_baseline.ipynb](../../notebooks/lab3_baseline.ipynb).
Таблица всех 42 попыток: [requests.csv](../../ml/experiments/evidence/requests.csv).

Для нового обращения к Mistral задаётся личный `MISTRAL_API_KEY` и отдельный
каталог результатов; используется подтверждённый Free-аккаунт:

```powershell
python ml/experiments/run_iteration.py --run --output ml/experiments/new-run
```
