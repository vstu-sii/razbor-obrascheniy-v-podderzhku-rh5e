# Первые эксперименты

Цель — сравнить direct prompt и RAG на одинаковых 10 синтетических примерах: категория, срочность, summary, поиск статьи, чек-лист, черновик и решение о вызове оператора.

Для запуска фиксируются дата, модель, версия prompt, параметры, токены, latency и полный JSON. Ноутбук: `notebooks/lab1_prompt_experiments.ipynb`.

Проверки: релевантная статья, отсутствие статьи, неполные данные, длинная история, сложное обращение, prompt injection, вредоносная вставка в документе.

До фактического прогона нельзя заявлять качество модели. Рабочий кандидат — RAG + structured output; он делает карточку интегрируемой, но требует отдельной проверки содержательных значений.
