# LAB04: зафиксированный объём MVP

29.10.2026 я зафиксировал границы учебного MVP. Событие нового обращения или сообщения клиента ставит задачу в очередь. Оператор открывает подготовленную карточку и проверяет результат.

| Возможность | Результат | Основание |
| --- | --- | --- |
| Подписанные события и очередь PostgreSQL | Разбор без кнопки запуска | D-012 |
| Дедупликация и версии | Повтор события не создаёт лишнюю задачу, старая карточка не подтверждается | EVT-02–07 |
| Попытки, квоты и деградация | Перегрузка имеет понятный исход | D-015, Q-010 |
| Карточка и источники | Видны сводка, факты, пробелы и основание | PRD v3 |
| Решение оператора | Исходное предложение и правка сохранены отдельно | UC-04 |
| Публичный стенд | HTTPS, защищённый API | D-016 |
| CI/CD, staging и мониторинг | Выпуск проходит через проверки, откат сохраняет данные | D-015–017 |

Режимы предложения: answer, clarify, escalate. Отказ разбора имеет статус not_analyzed. Answer ограничен точной цитатой актуальной утверждённой статьи. Применимость статьи и факты сводки проверяет оператор.

За границей MVP оставлены автоматическая отправка ответов, реальная helpdesk-интеграция, выдача доступа, операции с деньгами, реальные персональные данные, вложения, мультитенантные права и промышленная нагрузка. Подтверждение сохраняет решение в учебной БД.

Мониторинг работает в локальном Docker по решению участника. Render Free используется для демонстрации и может засыпать. Постоянный размещённый мониторинг и SLA в объём не входят.

Относительно LAB03 добавлены защита ответа по цитате, инструкции v2.1, общие ограничения расхода, автоматический выпуск и проверка отката. Явная ошибка импорта CSV относится к product_error, обычная настройка API относится к integrations.

Scope зафиксирован для приёмки 29.10.2026. Дальнейшее изменение записывается с причиной, владельцем и влиянием на остаток.
