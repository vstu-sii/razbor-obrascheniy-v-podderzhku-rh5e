## Что обнаружено и исправлено при review 15.10.2026

Предыдущая версия сохраняла предложение и review, но теряла исходное обращение
при повторном открытии, не показывала историю решений, не требовала отдельного
подтверждения и не сохраняла очередь эскалации. В UI принятие изменённого
черновика могло незаметно сохранить исходный текст.

Исправления внесены в общий runtime: API-валидация, сохранение контекста,
транзакционные миграции 001/002, ограничения SQLite и интерфейс. Добавлены
7 регрессионных тестов Delivery, реальная browser-проверка Edge и Docker smoke
с проверкой сохранения после restart. Существующий API-тест Quality получил
поле подтверждения. Новые тесты подключены к существующему eval workflow.

Пройденный путь: UI → API → локальный извлекающий baseline → SQLite; отдельное
решение оператора хранится независимо от исходного proposal. Локальные trace
метаданные создаются в persistent volume. Это не вызов живой генеративной LLM.

## Что ещё не выполнено

Публичный деплой, подтверждённый Langfuse dashboard, вызовы живой модели,
независимый walkthrough и командная приёмка не заявляются успешными.
SQLite и один процесс остаются явным упрощением целевой архитектуры LAB02;
перенос в нормализованный PostgreSQL требует отдельного согласования.
Исторический прод-адрес из LAB01 возвращает 403 из среды проверки.
Нужен реальный хостинг с постоянным диском и доступом для обновления приложения.
