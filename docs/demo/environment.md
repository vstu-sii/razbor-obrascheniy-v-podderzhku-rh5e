## Однокомандный сброс данных

Из корня учебной ветки: `python scripts/demo-seed/reset.py --reset`.
Создаётся шесть синтетических обращений и дополнительная учебная запись
решения через настоящий review-endpoint. Это действие скрипта, а не человеческое
одобрение и не наблюдение North Star. Источники сохранённых ответов известны заранее.
Это локальные данные, не seed публичного сайта. Параметр --db разрешает выбрать
отдельный SQLite-файл; неизвестный существующий файл не перезаписывается. Перед сбросом остановить локальный сервер. Новая база готовится отдельно, предыдущая сохраняется в `.bak`.

Тестовый локальный код указан в [плане Б](plan-b.md); production-код не хранится
в Git. Запуск `python scripts/demo-seed/serve.py` слушает только 127.0.0.1:18096.
Для production нужны существующий код оператора и согласованный бюджет.
