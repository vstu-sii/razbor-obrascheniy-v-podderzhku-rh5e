# SCOPE-03: снимок объёма MVP

Дата фиксации источника в Git: 2026-10-27. Источник: [Git 84d544e](https://github.com/SIISKI/siiski_volchkova_shared_repository/blob/84d544ed8a1194e91b27fdae5cc60578975e785a/project/docs/mvp-scope.md).

Оператор русскоязычного B2B SaaS получает карточку обращения автоматически
после события. В учебном стенде один условный сервис, синтетические обращения
и шесть статей. Гипотеза сегмента из LAB01 не подменяется реальным исследованием.

Включены: подписанные события и доверенный снимок, долговечная очередь,
устранение дубликатов, актуальная версия, ограниченные попытки/нагрузка,
четыре режима, источники, сохранение решения и исправленного текста,
локальный staging/мониторинг/откат, автоматические quality gates.

Answer ограничен точной актуальной approved-цитатой. При нехватке данных
предлагается уточнение; риск/отсутствие основания переводятся специалисту
или в ручной исход. Внешнее действие требует будущей helpdesk-интеграции:
сейчас подтверждение только сохраняет решение в БД, клиенту ничего не отправляет.

Исключены: автодействия от модели, реальные деньги и персональные данные,
мультитенантные ACL, вложения, production-нагрузка. Публичный Render передан
Delivery отдельно. Нельзя объявить MVP готовым к клиентам по одному green CI.

Новые общие правила категорий: явная ошибка импорта CSV и массовый сбой —
product_error; обычный вопрос о настройке API — integrations. Режим и категория
независимы. Эти правила реализованы в общем коде и не привязаны к ID примеров.
