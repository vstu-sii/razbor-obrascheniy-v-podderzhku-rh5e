Даты исторических версий относятся к редакциям в истории Git. В каждом снимке указаны исходный commit и путь документа. Для LAB02 сохранены разделы с границами MVP, для LAB04 сохранён текст scope. Первоначальные формулировки остаются в снимках. Действующие названия режимов и границы задаёт текущая редакция.

Новая версия создаётся при изменении функции, границы, результата UC или условий приёмки. Если в одной редакции несколько решений, каждое получает отдельный SC-ID в журнале. Изменение статуса проверки связывается с существующим решением и его основанием.

SCOPE-05 представлен в обезличенной копии от 01.11.2026. Исходная контрольная сумма сохранена в рабочем реестре источников. Функциональные границы не изменены.
