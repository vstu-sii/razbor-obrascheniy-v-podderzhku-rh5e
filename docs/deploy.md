## Что делает владелец Render

1. Открывает существующий сервис, не создаёт платные сервисы/новую БД.
   DEVELOPMENT теперь находится в GitHub организации SIISKI. Если Render потерял
   доступ после переноса, владелец восстанавливает подключение к тому же
   репозиторию в SIISKI; публичность репозитория менять не нужно.
2. В Settings выбирает ветку DEVELOPMENT `lab03/delivery/d-012-event-runtime`.
   Root Directory: `project`, Dockerfile Path: `./Dockerfile`.
3. Сохраняет существующий DATABASE_URL Neon, код оператора и остальные секреты.
   BASELINE_MODE=extractive. START_WORKER=true либо переменная отсутствует.
   AI_BASE_URL оставляется пустой: в одном Render сервисе используется тот же
   AI-модуль локально, без ссылки на контейнер ai из Compose.
4. Запускает Manual Deploy → Deploy latest commit и ждёт Live.
5. Открывает /health: status=ok и architecture=event-queue-v1. Фиксирует commit
   из панели и время, затем создаёт синтетическое обращение через UI.
6. Проверяет queued/running → карточка, сохраняет решение, создаёт новую версию
   того же тикета и проверяет отказ от подтверждения старой карточки.
7. Перезапускает сервис и проверяет сохранённые карточку и решение, не делая
   скриншотов с паролями/кодом доступа. Передаёт дату, commit и результат команде.

Публичный URL использует HTTPS без :10000. Docker слушает 0.0.0.0:$PORT.
Миграции 001–003 применяются автоматически с advisory lock, без удаления старых
карточек/review. Возврат старого образа не откатывает additive SQL-миграции.
Перед обновлением владелец проверяет доступность резервного восстановления БД.

## Доступ

Код оператора хранится в app_settings (`setting_key='operator_token'`), если не
задан явно через DEMO_OPERATOR_TOKEN. Участник получает его только в своей
Neon SQL Editor/Render панели и передаёт преподавателю отдельно. В открытый PR
код не включается. SERVICE_TOKEN и EVENT_SECRET генерируются отдельно в этой
же приватной БД. Не заменять ими код оператора и не публиковать значения.

UI и /health открыты; /api/proposals, /api/tickets и /api/traces без Bearer
отвечают 401. Это ожидаемая защита. Общий trusted adapter может сохранить снимок
через /internal/snapshots, затем доставить HMAC-SHA256 подпись сырых байтов JSON
в X-Event-Signature к /ingress/events. В Compose внешний ACL доступен на :8001/events.
Не подтверждённый HTTP 503 источник должен сохранить и повторить.

Render Free может засыпать. Это учебный прототип, постоянная доступность/SLA
не заявляется. PostgreSQL хранит и очередь, и метаданные трасс. Настоящий dashboard
Langfuse и живой LLM требуют уже предусмотренных параметров от AI Engineer;
локальная трасса не доказывает работу внешнего Langfuse.
