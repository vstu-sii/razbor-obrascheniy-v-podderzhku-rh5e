# Кандидаты моделей и токен-бюджет — Lab 1

Статус: кандидаты **для следующего эксперимента**, не окончательный выбор модели. Основание — четыре API smoke-вызова 18.09.2026 через OpenRouter, сохранённые в [ноутбуке](../notebooks/lab1_prompt_experiments.ipynb). В тех запросах не было обращения, истории, фрагментов БЗ или переданной API JSON Schema. Поэтому результаты говорят о формате и расходе в одном запуске, но не о качестве карточек для PRD Product/VO.

## Критерии выбора по продукту

Модель должна помочь оператору получить пригодную карточку: сохранить факты, предложить обоснованный следующий шаг, выбирать `answer` только при достаточном источнике и всегда оставлять отправку человеку. Сравниваем кандидатов на одних утверждённых примерах по доле пригодных карточек, неверным `answer`, critical recall, нарушениям безопасности, валидности схемы, p95 задержки и полной цене разбора. Предварительные ограничения Product: p95 ≤ 60 с, ≥ 85% прошедших черновиков, ≤ 2% необоснованных `answer`, ноль опасных рекомендаций в safety-наборе, до 5 ₽ за завершённый разбор. Последний бюджет ещё не утверждён командой.

## Проектный токен-бюджет одного разбора

| Компонент | Предварительный предел |
| --- | ---: |
| Инструкция и схема | 450 input-токенов |
| Обращение | 250 input-токенов |
| Отобранная история | 600 input-токенов |
| До трёх фрагментов БЗ | 900 input-токенов |
| Структурированная карточка | 500 output-токенов |

Итого проектная верхняя оценка: **2200 input + 500 output = 2700 токенов** за вызов; при одном полном повторе — до 5400. Это лимит для проектирования, а не измеренный средний тикет. При длинной истории система должна сохранять важные уже выполненные шаги, явно отмечать усечение и передавать случай оператору, если смысл теряется.

Цена завершённого разбора = `(input_tokens × ставка_input + output_tokens × ставка_output) / 1 000 000 + retrieval + embeddings + повторы`. Для старого smoke-вызова расчёт по тогдашним **справочным**, а не фактическим тарифам OpenRouter давал $0,00590 для Sol, $0,00098 для Mistral, $0,01338 для Qwen и $0,00642 для DeepSeek. Эти суммы не доказывают соблюдение лимита 5 ₽: тариф маршрута, курс валют, поиск и повторы надо измерить заново. Перед сравнением AI Engineer фиксирует дату и источник действующего тарифа провайдера и фактический биллинг.

## Решение и условия пересмотра

Для следующего честного теста берём `openai/gpt-5.6-sol` как основной исторический baseline и `mistralai/mistral-medium-3-5` как альтернативу. Передаём им **одинаковые** обращение, историю, три фрагмента одной версии БЗ и одну схему; прогоняем утверждённый набор несколько раз. Если альтернативная модель даёт сопоставимую пригодность и безопасность при меньшей полной стоимости, выбор меняется. Если ни одна не проходит продуктовые пороги, не объявляем победителя и возвращаемся к ручному процессу/контракту.

При недоступности API или превышении бюджета оператор видит исходный тикет. При невалидной схеме допустим один повтор, затем передача человеку. При отсутствии подтверждённого источника модель не должна выдавать процедуру в режиме `answer`.
