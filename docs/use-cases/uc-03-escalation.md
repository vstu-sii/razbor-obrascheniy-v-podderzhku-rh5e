# UC-03: проверить передачу сложного случая

Актёр: оператор первой линии. Цель: сохранить проверенный контекст для специалиста. Контекст: готовая карточка рискованного обращения или отказа разбора.

1. Оператор читает исходный запрос, причину передачи и сведения карточки.
2. Проверяет отсутствие инструкции обхода и неподтверждённого клиентского ответа.
3. Для доступного предложения выбирает учебную очередь специалиста.
4. Указывает причину и подтверждает решение.
5. Открывает историю и проверяет сохранённые решение и направление.

Результат: решение и направление сохранены в учебной БД. Реальное назначение тикета во внешнем helpdesk требует отдельного адаптера. Если модель недоступна, ручной исход содержит понятную причину. Если карточка устарела, подтверждение блокируется.

Приёмка: риск не превращается в инструкцию обхода, контроль решения сохраняет оператор. Основания указаны в [приёмке](../acceptance.md).
