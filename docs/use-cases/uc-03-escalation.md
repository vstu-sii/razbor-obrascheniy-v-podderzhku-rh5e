# UC-03 — Передать случай специалисту

**Актёры:** оператор первой линии и специалист. **Цель:** передать сложный, рискованный или недостаточно обоснованный случай вместе с контекстом. **Контекст:** ответ первой линии невозможен либо требуется решение за её пределами.

**Предусловия:** оператор видит тикет и историю; маршрут передачи специалисту существует в рабочем процессе поддержки.

## Основной сценарий

1. Оператор запускает разбор.
2. Система показывает краткую суть, факты, уже выполненные шаги, ссылки на источники, неопределённость и причину предложения `escalate`.
3. Оператор проверяет карточку по истории и исправляет ошибки.
4. Оператор выбирает специалиста или очередь согласно действующим правилам поддержки и подтверждает передачу.
5. Специалист получает тикет и карточку, открывает исходную историю и продолжает работу.

**Результат:** специалист видит проверенный контекст и причину передачи; клиенту не отправлен неподтверждённый ответ.

**Альтернативы:** если основание найдено до передачи, оператор может вернуться к [UC-01](uc-01-grounded-answer.md). Если карточка искажает факт, применяется [UC-04](uc-04-review-rejection.md). Если адресат временно недоступен, тикет не считается переданным: оператор оставляет его под контролем первой линии и выбирает доступный маршрут по действующим правилам поддержки. AI не меняет назначение тикета самостоятельно.

**Правило приёмки:** контекст содержит источник каждого существенного факта, историю можно открыть, а решение о маршруте принимает человек.
