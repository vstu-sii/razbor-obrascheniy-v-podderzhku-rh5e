# UC-04: исправить или отклонить предложение

Актёр: оператор первой линии. Цель: зафиксировать собственное решение и сохранить исходное предложение. Контекст: актуальная автоматически подготовленная карточка.

1. Оператор сравнивает предложение с источником и историей.
2. Исправляет только поле текста решения, указывает причину.
3. Сохраняет исправление через отдельную кнопку и подтверждает диалог.
4. При отклонении указывает причину и подтверждает rejected.
5. Открывает ту же карточку и сверяет исходное предложение и отдельные решения.

Результат: правка не переписывает предложение AI, отклонение имеет пустой итоговый текст. Новая версия обращения блокирует подтверждение старой карточки. Review не запускает модель повторно. Клиенту сообщение не отправляется.

Приёмка: edited и rejected различимы, сохраняются после открытия, исходные сведения доступны. Основания указаны в [приёмке](../acceptance.md).
