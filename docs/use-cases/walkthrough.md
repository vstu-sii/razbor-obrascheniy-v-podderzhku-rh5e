## Что установлено

Предложения читаются после перезапуска сервера. Экспорт сравнивает JSON каждой
сохранённой карточки с её исходной final_card в trace. Review не меняет предложение,
а rejected не содержит итогового текста. Это проверяемые свойства БД и API.
Участник подтвердил видимость решений и понятность после объяснения.
Затруднения первой попытки сохранены, поэтому самостоятельная понятность
интерфейса не считается доказанной.

Прохождение нескольких синтетических UC не доказывает общую точность модели,
продуктивность оператора, соответствие промышленным порогам или публичную
доступность системы. Метрики большого учебного прогона находятся в отдельном
отчёте об ошибках, эти данные не смешиваются с walkthrough.
