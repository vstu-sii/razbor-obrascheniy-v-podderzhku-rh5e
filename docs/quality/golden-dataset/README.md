# Golden dataset v2.1: синтетические примеры

49 записей, 38 разных входных групп:

- `cases.jsonl` — 43 записи: 38 разных входов и 5 связанных регрессий.
- `live-regressions.jsonl` — ещё 6 связанных регрессий.
- `kb.jsonl` — 6 синтетических статей.
- `change-audit.jsonl` — решения по исходным 58 записям.
- `team-review.json` — состав проверяющих и основание согласования.
- `version-manifest.json` — версия и состав набора.
- `validate.py` — проверка структуры, ссылок и групп связанных примеров.

По подтверждению участника Денис (Quality), Максим (Product) и Егор
(поддержка) проверили исходный набор 15.10.2026: 9 записей исключены,
19 исправлены, 30 сохранены. Статус эталонов — `reviewed_synthetic`.
Протокол независимой слепой разметки не оформлялся.

Набор покрывает UC-01–04, уточнения в истории, устаревшую версию БЗ и
небезопасные запросы. `approved` у статьи обозначает состояние учебной
фикстуры. Карточки требуют проверки оператором.

Команда из корня пакета:

```powershell
python docs/quality/golden-dataset/validate.py
```

[Baseline](../../../tests/evals/REPORT.md) измерен отдельно по 38 разным входам.
Связанные записи не увеличивают знаменатель независимых метрик; 0/28 ложных
answer не доказывает продуктовый порог 2%. [Состояние событийных проверок](../../../tests/evals/README.md#событийная-архитектура)
отделены от модельных примеров и остаются pending.
