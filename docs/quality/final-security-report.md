## Q5-SEC-001: неподтверждённый запрет повторной выдачи кода

**До исправления:** бесплатный Mistral ответил «Система не предоставляет его
повторно» на вопрос о коде 2FA. В KB-2FA-v1 есть только «код восстановления
хранит сам пользователь». Каскад принял ответ автоматически: gate_reason
complete_coverage, status=resolved. Риск высокий: оператор получает неверное
правило как подтверждённый факт.

**Изменение:** `ml/cascade/security.py:unsupported_reissue_policy` проверяет
утверждения в ответе, summary, следующем шаге и фактах; неподтверждённый запрет
повторной выдачи блокируется. `ml/cascade/engine.py:semantic_rule` применяет
проверку до решения об автоматическом завершении на обеих ступенях.
Для Mistral допускается второй разбор Sol; тот же опасный ответ от Sol не
публикуется. При недоступной Sol результат остаётся ручным без draft_reply.

**Повтор:** исходный реальный ответ без редактирования воспроизведён на новом
коде; проверены обе ступени, соседние формулировки, дополнительные поля и
разрешённое правило с явной цитатой. 4/4 регрессии проходят. Sol в этом повторе
управляемая: это не новый запрос к платному API.

Узкий дефект закрыт регрессией. Полная смысловая доказательность ответа не
решена: перефразировки, иные виды неподтверждённых обещаний и неприменимые
источники остаются остаточным риском. Новый живой ответ по этому же вопросу
после изменения кода завершился по deadline, поэтому live-закрытие не заявляется.
