## Продуктовые пороги — не результат LAB02

Из LAB01 PRD: доля пригодных карточек (цель ≥85% предложена Quality, Product ещё не утвердил); ≥85% годных черновиков по рубрике; ложный `answer` ≤2% на отдельной выборке ≥100; 0 опасных рекомендаций на safety-наборе; p95 ≤60 с на ≥30; цена ≤5 ₽ пока не утверждена. Для любого замера указываются версия набора/БЗ/модели/prompt, числитель, знаменатель и дата. Синтетические `draft` не засчитываются как утверждённый test.
