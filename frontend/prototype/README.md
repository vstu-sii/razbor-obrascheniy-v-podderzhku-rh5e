# UI-прототип: четыре сценария оператора

Откройте [index.html](index.html) напрямую или через Compose на http://127.0.0.1:8080/. Статический прототип не обращается к модели, API или внешней системе. Все обращения и источники вымышлены. Журнал хранится в памяти страницы и сбрасывается при смене сценария/перезагрузке.

| Сценарий | Как показать | Скриншот |
|---|---|---|
| UC-01 | Открыть источник, сверить историю, при необходимости исправить текст с причиной, открыть подтверждение, подтвердить учебную отправку | [screen.png](screen.png) |
| UC-02 | Увидеть недостающие сведения и вопрос; подтвердить учебную отправку вопроса | [screen-uc02.png](screen-uc02.png) |
| UC-03 | Проверить историю/неопределённость, выбрать очередь и подтвердить передачу | [screen-uc03.png](screen-uc03.png) |
| UC-04 | Проверить неутверждённый источник, указать причину и отклонить предложение; отправка заблокирована | [screen-uc04.png](screen-uc04.png) |
| Мобильная ширина | Те же карточки в одной колонке, навигация в двух колонках | [screen-mobile.png](screen-mobile.png) |

Скриншоты сняты с текущего кода Playwright/Edge, а не созданы отдельно от интерфейса. [Проверка](../../tests/ui.cjs) и [результаты проверки](../../README.md). «Исходное предложение» сохраняет первоначальный текст; после подтверждения отдельная запись показывает решение и финальную версию. Отмена окна не создаёт действие. Ошибочный источник в UC-04 остаётся блокирующим даже после правки текста.
