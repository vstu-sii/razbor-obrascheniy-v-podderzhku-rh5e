# Прототип событийного разбора LAB02

Открыть [index.html](index.html) или http://localhost:18086 при запущенном Compose.
Актуальный [скриншот](screen-events.png). Стендовые события → queued → running → ready.
Просмотр не вызывает inference. Новая версия блокирует подтверждение старой;
дубли и внутренние заметки не добавляют задач. Все данные синтетические, память
страницы сбрасывается при reload, внешних действий нет. Остальные screen*.png
сохранены как исторические изображения прежней версии, не текущий интерфейс.
