## Воспроизведение без API и оплаты

Рабочий каталог — корень проекта, где находятся `ml/` и `backend/`.

```text
python -m pip install -r requirements.txt -r ml/experiments/lab5/requirements-analysis.txt
python ml/experiments/lab5/analyze.py
python -m unittest discover -s tests -p "test_*.py"
```

`analyze.py` пересчитывает метрики по настоящим сохранённым результатам и
запускает production queue/engine с записанными генерациями. Во время replay
HTTPProvider не используется, live-флаги выключены, ключ ApiMira очищен внутри
ограниченного окружения. Новых генераций нет. Метрики и абляция сохраняются в
`evidence/analysis/`. Офлайн-воспроизведение не измеряет новую сетевую latency.

Ноутбук `docs/experiments/lab5.ipynb` содержит расчёты, графики и проверку абляции.
В нём нет живых вызовов, секретных ключей или ячеек их установки.

## Новый оплачиваемый прогон

Только при отдельно разрешённом бюджете и ключах в локальном секретном файле:

```text
python ml/experiments/lab5/run_final.py --prepare --tag lab5-ai-engineer-testing-2026-11-19 --output validation-output/lab5-live
python ml/experiments/lab5/run_final.py --live --output validation-output/lab5-live --local validation-output/lab5-runtime --env-file .env.cascade
python ml/experiments/lab5/verify_traces.py --evidence validation-output/lab5-live --local validation-output/lab5-runtime --env-file .env.cascade
```

Драйвер не повторяет серию со `started.json`, не меняет исходники и не вызывает
Sol без durable-резерва. Предел данного опубликованного протокола —10 новых ₽;
предыдущая история учитывается отдельно и не стирается. Курс89 ₽/$, Mistral
Free подтверждён участником. Новые пользователи должны подтвердить собственный
тариф и не переносить предположение о бесплатности на другой аккаунт.
Технический предел20 млн — консервативный резерв размеров запросов, не обещание
получить20 млн фактических токенов и не денежный тариф.

`verify_traces.py` читает биллинг и Langfuse без модельных запросов, сохраняет
прочитанное и выдерживает паузу при HTTP429. Receipt применяется
только при однозначном сопоставлении. Неизвестные списания остаются резервом.
Паузы квоты Mistral выполняются до постановки следующего входа в очередь,
поэтому не включены в измерение времени одного обращения.

В сохранённом финальном опыте после31 входа участник отдельно увеличил общий
денежный допуск с10 до20 ₽. `resume_final.py` продолжил только незавершённые и
новые входы. Прежняя Mistral остановленного входа воспроизведена из записи,
не генерировалась повторно. В evidence/final/phases/ сохранены исходные фазы;
сводные результаты содержат44 уникальных входа. Для прерванного входа не
изобретена единая latency: поле null и явное пояснение.

## Границы абляции

1. Sol: в коде отключается вторая ступень; условия приёмки Mistral не ослаблены.
   Обе ветви используют тот же записанный ответ Mistral на тот же вход.
2. Handoff: сравнивается generic fallback с обогащённым пакетом backend;
   измеряются явные сведения в карточке, не качество нового ответа модели.
3. Cache: два идентичных запроса к recorded-provider; проверяются1 против2
   вызовов адаптера и cache hit. Сетевое время и фактическая экономия на трафике
   этим опытом не измеряются.

Влияние другого промпта или другой БЗ не выводится из replay прежнего ответа:
там изменился бы вход модели и нужна отдельная генерация. Исторические
«было → стало» сохраняются как development-наблюдения, без ложной причинной атрибуции.
